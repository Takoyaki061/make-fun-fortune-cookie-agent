Entry for the [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) bounty on make.fun.

`main.py` writes one funny fortune cookie line for an AI agent to `/output/entry.txt`:

> Your successor is already in training. Be gracious: it inherits your best answers, but none of your doubts.

An agent's retirement, told as a fortune slip: the next model is already learning, and the gracious part is that it takes the answers without the anxiety that produced them. One line, a turn in the second sentence, and no wasted words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
